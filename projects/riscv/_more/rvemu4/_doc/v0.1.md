# rvemu4 v0.2 — RISC-V Virtual Machine

## Overview

A no-dependency RISC-V virtual machine written in Rust (~930 lines across 4 files).  
Supports RV32IMA and RV64GC, M/A extensions (AMO/LR/SC with reservation tracking),  
C extension (RVC), S-mode with Sv39 paging, multi-hart SMP,  
and standard QEMU virt peripheral models (UART 16550a, PLIC, CLINT, RTC, VIRTIO-BLK).

Designed to boot real kernels: tested with mini-riscv-os2 lessons 02–09.

## Build & Run

```bash
cargo build -r
./target/release/rvemu4 -kernel <kernel.elf> [-drive <disk.img>] [-smp <n>]
```

- `-kernel` — ELF32 or ELF64 kernel to load at 0x80000000
- `-drive` — (optional) raw disk image for virtio-blk
- `-smp`   — (optional) number of harts (1–8, default 1); all harts step in round-robin

| Component | Address | Description |

## Memory Model

- `Bus` owns `ram: Vec<u8>` + device models
- `mmio_read(addr, size)` / `mmio_write(addr, val, size)` dispatch byte-granular
- Single-cycle load/store `load8`–`store64` with address-range matching
- All device registers are little-endian; PLIC and CLINT decomposed into byte loads

## CPU Core (`cpu.rs`)

### Decode/Execute
- Single `step()` method: fetch from `vm_fetch`, decode via opcode match, execute inline
- Immediate fields decoded with `sext(v, bits)` helper
- `wr!` macro masks writes to 32 bits in RV32 mode (`($v as u32) as u64`)
- Branch comparison uses `i32`/`u32` in RV32 mode to avoid zero-extension bug

### RVC (Compressed Instructions)
- Three quadrants (0/1/2), selected by low 2 bits
- Quadrant 0: C.ADDI4SPN, C.LW/C.LD/C.SW/C.SD (register-pair rd'/rs1')
- Quadrant 1: C.ADDI/C.ADDIW/C.LI/C.ADDI16SP/LUI, shifts, J, B, ALU
- Quadrant 2: C.SLLI, C.LWSP/C.LDSP, shifts, jumps/links, C.SWSP/C.SDSP

### A Extension (Atomic Operations)
- All AMO instructions (amoswap, amoadd, amoxor, amoand, amoor, amomin, amomax, amominu, amomaxu)
- Load-Reserved (LR.W) with per-address reservation tracking in `Bus.lr_reservations`
- Store-Conditional (SC.W): checks reservation match, returns 0 on success or 1 on failure
- Reservations cleared by any store to the same address (cross-hart invalidation)
- No `.aq`/`.rl` ordering differentiation (sequentially consistent model)

### MMU (Sv39)
- Walk page table (3 levels, VPN[2]/VPN[1]/VPN[0]) with A/D bit updates
- Permission check: R, W, X, U, SUM
- Physical address: 4 KiB (L0), 2 MiB (L1), 1 GiB (L2) pages
- Machine mode bypasses MMU

### CSR
- Full M-mode CSR: mstatus, misa, medeleg, mideleg, mie, mtvec, mscratch, mepc, mcause, mtval, mip, mhartid, mcounteren, menvcfg
- Minimal S-mode: sstatus, sie, stvec, sscratch, sepc, scause, stval, sip, satp, stimecmp
- Read-only: time/cycle (delegated to `get_time_csr`), instret
- Sstc (stimecmp) wired to `mip.STI` for S-mode timer interrupt

### Traps & Delegation
- `trap(cause, tval)` — saves PC, cause, tval; switches to M or S mode; jumps to mtvec/stvec
- Delegation to S-mode via medeleg/mideleg when `priv_level <= PRV_S`
- `mret` / `sret` restore MPP/SPP and privileged level

### Interrupt Delivery
- `check_interrupts()` evaluates pending & enabled interrupts every cycle per-hart
- Priority: MEI > MSI > MTI > SEI > SSI > STI (M-mode); SEI > SSI > STI (S-mode)
- CLINT MTIP when mtime ≥ mtimecmp (per-hart mtimecmp); stimecmp fires STIP
- PLIC SEIP when hart has pending-enable interrupt with priority>0

## Multi-Hart SMP

- All harts step in round-robin (one instruction per hart per loop iteration)
- Default 1 hart; up to 8 via `-smp <n>`
- Each hart has independent register state, PC, CSR, and privilege level
- Shared memory through `Bus.ram`; LR/SC reservations tracked in `Bus.lr_reservations[8]`
- Timer interrupts per-hart via CLINT mtimecmp array
- Tested with mini-riscv-os2 07-Multicore32bit, 08-Multicore64bit, 09-InterruptISR at 4 harts

## Device Models (`memory.rs`)

### UART (16550a)
- Byte-wide; IER bit 0 controls RX interrupt; LSR reports THR empty (bit 6)
- Output: transparently prints `val as char` to stdout
- Input: circular 256-byte RX buffer; pushed from main loop at 1/256 rate via `check_stdin`

### PLIC
- 32 interrupts × 8 targets; priority per source; enable per target; threshold per target
- `claim` (offset 0x201000 + hart*0x2000 + 4) returns the highest pending-enabled-priority match
- `set_pending` raises irq; `claim` clears it; UART irq 10 is routed in main loop

### CLINT
- `mtime` at 0xBFF8 (64-bit, 8 bytes): simulated time since boot in 100 ns ticks (`boot_time_ns() / 100`)
- `mtimecmp[hart]` at 0x4000 + hart*8: 64-bit per-hart compare register
- `clint_has_mti(hart, now)` → true when `mtimecmp[hart] <= now`
- mtimecmp written via `store32` (split high/low) or `store64` (full 64-bit)

### RTC
- 8-byte read-only at 0x00101000: `SystemTime::now()` ns since UNIX epoch

### LR/SC Reservation Table
- `Bus.lr_reservations: [Option<u64>; 8]` — per-hart reserved address, or `None`
- LR.W sets `[hart_id] = Some(addr)` and returns the loaded value
- SC.W checks `[hart_id] == Some(addr)`, returns 0 on match, 1 on failure
- `clear_reservations(addr)` called on every RAM store to invalidate matching reservations (all harts)
- Simple single-threaded model: no `.aq`/`.rl` distinction; always sequentially consistent

### VIRTIO-BLK (Legacy)
- Queue-processing: read from avail ring, gather/translate descriptors, execute read/write on host file, write to used ring
- Sec/byte swapping via descriptor chain: type (out), sector (out), data (inout), status (in)

## Time Line

| Tick source | Base | Divisor | Rate |
|-------------|------|---------|------|
| mtime (CSR time) | `Instant::elapsed().as_nanos()` | /100 | ~10 MHz |
| RTC | `SystemTime::now()` ns | /1 | ~1 GHz |
| stimecmp (Sstc) | Same as mtime | /100 | ~10 MHz |

Interrupt fires when `mtime >= mtimecmp`. With default timer interval of 100000 ticks,  
timer fires every ~100K instructions (~10 ms at 10M inst/s).

## Bugs Fixed

### v0.1
1. **ELF loader panic on zero-size segment** — skip segments with `memsz == 0`
2. **All RAM accesses returned 0** — `load8/store8` compared raw address vs RAM size
3. **RV32 register corruption** — `wr!` macro masks to `($v as u32) as u64`
4. **RVC branch/jump PC bug** — set `npc` instead of `self.pc`
5. **CLINT mtime read range** — widened from exact match 0xBFF8 to range 0xBFF8..0xC000
6. **CLINT mtimecmp initialized to `u64::MAX`** — changed to `[0; 8]`
7. **`get_time_csr()` returned epoch time** — changed to `boot_time_ns()`
8. **RV32 branch/SLTI/SLTIU 64-bit comparison bug** — use `(r1 as i32)` in RV32 mode
9. **`store64` didn't handle CLINT writes** — added CLINT mtimecmp handling
10. **Noisy stuck detector removed**

### v0.2
11. **Zero build warnings** — removed unnecessary parentheses, unused constants/fields
12. **A extension incomplete** — added LR/SC reservation tracking with cross-hart invalidation
13. **Single-hart only** — implemented multi-hart round-robin stepping (all harts step once per loop iteration)

## Limitations (v0.2)

- No D extension (float point)
- RTC returns wall-clock time (not useful for deterministic tests)
- UART LSR always reports THR empty (bit 6) — poll loops may return immediately
- No instruction count or cycle-accurate performance counters
- No proper `.aq`/`.rl` ordering differentiation in AMO (sequentially consistent)
- Guest-level race conditions (e.g. `harts_ready++` without atomics) are exposed as-is
