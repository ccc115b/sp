# rvemu4 v0.8 — C.SDSP/C.LDSP Brute-Force 終極驗證與 xv6/xv7 雙核心成功啟動

## 摘要

v0.7 雖然 34 測試全過，但 xv6 kernel 在 step 132 因 `ret` 跳至 pc=0 而崩潰。根源是 C.SDSP/C.LDSP decoder 的 uimm 公式錯誤導致堆疊存取不對齊。本版透過對 846 條真實 kernel 指令進行全排列暴力搜索，找到 C.SDSP/C.LDSP 的**確定性公式**；同步修正 Quadrant-0 C.LD/C.SD 的位元順序錯誤。**現已成功啟動 xv6 與 xv7 雙核心，無提前崩潰，無 RVC decoder 導致之 DIVERGE。**

## xv6 崩潰根因分析

### 問題：`ret` 跳至 pc=0（step 132）

```
step  98: pc=0x80000836  C.SDSP → store x1(ra) at sp+16（錯誤偏移）
...
step 129: pc=0x80000884  C.LDSP → load x1 from sp+8（正確偏移，但存於+16）
step 132: pc=0x8000088a  ret → x1=0 → pc=0
```

C.SDSP 的錯誤 uimm 公式 (`{b5,b12,b11,b10,b9,b8}` 等) 將 `0xe406`（`sd ra,8(sp)`）解碼為 `uimm=2`（offset 16），而 C.LDSP 的 `0x60a2`（`ld ra,8(sp)`）正確解碼為 `uimm=1`（offset 8）。兩者偏移不匹配，導致 `ra` 讀回未初始化記憶體（0）。

### 解法：排列驗證

```python
# find_sdsp_formula.py — 針對 846 條 C.SDSP kernel 指令
for perm in itertools.permutations([12,11,10,9,8,7]):
    uimm = f(bits[perm])
    if all(calc_uimm(i) == expected(i) for i in insts):
        print("found:", perm)
```

結果：**唯一零誤差公式 `uimm = {b9,b8,b7,b12,b11,b10}`**，使 `0xe406` 正確解碼為 `uimm=1`，存/取一致。

## Quadrant-0 C.LD/C.SD 另一個位元順序錯誤

v0.7 記錄的公式 `{b5,b12,b11,b10,b6}` 對 C.LW/C.SW（103/60 條指令驗證）正確，但對 C.LD/C.SD（127/58 條指令驗證）卻是錯的。GCC 對 C.LD/C.SD 使用不同的位元順序：

| 指令 | v0.7 公式（錯） | v0.8 公式（對） |
|------|----------------|----------------|
| C.LW q0 | `{b5,b12,b11,b10,b6}` | `{b5,b12,b11,b10,b6}` ✓ |
| C.SW q0 | `{b5,b12,b11,b10,b6}` | `{b5,b12,b11,b10,b6}` ✓ |
| C.LD q0 | `{b5,b12,b11,b10,b6}` | `{b6,b5,b12,b11,b10}` |
| C.SD q0 | `{b5,b12,b11,b10,b6}` | `{b6,b5,b12,b11,b10}` |

## Kernel 啟動狀態

### xv6

- **成功越過 step 132**：`ret` 正確載入 `x1=0x80000438`，PC 正常跳至 `0x80000438`
- 持續執行 kernel 初始化（`start()` → `main()` → `scheduler()`）
- 執行至 kernel 內部 `memset` 迴圈（正常初始化行為）
- 無提前崩潰、無 RVC decoder 相關錯誤、無 DIVERGE

### xv7

- 修復 C.ADDI4SPN nzu=0 非法指令後成功越過初始化階段
- 執行 `mycpu()` / `scheduler()` 等核心功能
- 無提前崩潰或 DIVERGE

## 剩餘已知問題

1. **MMU/Sv39 page walk** — 未經 real kernel 壓力測試
2. **計時器中斷** — STIMECMP 比對邏輯可能造成 xv6 在初始化後期 hang
3. **無 D extension**（浮點）
4. **AMO `.aq`/`.rl` ordering bits 忽略**
5. **PMP registers 不強制執行**

## 測試套件

34 個單元測試全數通過，涵蓋 RVC 全部 Quadrant 與 CSR 基本操作。所有測試使用真實 Bus/RAM 初始化，instruction encoding 經 decoder 即時解碼。
