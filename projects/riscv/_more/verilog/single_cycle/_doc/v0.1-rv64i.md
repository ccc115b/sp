# single_cycle v0.1 — RV64I 單週期處理器 (Verilog)

## 概述

以 Verilog 實作的 RV64I 單週期處理器（~266 行），支援 Icarus Verilog 與 Verilator 驗證。所有指令在一個 clock cycle 內完成，資料與指令記憶體彼此獨立（Harvard 架構）。

## 建置與執行

```bash
cd single_cycle
iverilog -o single_cycle_tb -g2012 rv64i_cpu.v tb_rv64i.v
vvp single_cycle_tb
```

相依工具：Icarus Verilog ≥ 12、Verilator ≥ 5.028（lint 用）。

## 支援指令集 (RV64I)

| 指令 | 類型 | 說明 |
|------|------|------|
| ADDI | I | 加法立即數，`x[rd] = x[rs1] + sext(imm_i)` |
| ADD | R | 加法，`x[rd] = x[rs1] + x[rs2]` |
| SUB | R | 減法，`x[rd] = x[rs1] - x[rs2]` |
| SLL/SRL/SRA | R | 邏輯/算術左/右移（shift amount = `rs2[5:0]`） |
| SLT/SLTU | R | 有號/無號小於比較 |
| XOR/OR/AND | R | 位元邏輯運算 |
| LB/LH/LW/LD | I | 載入位元組/半字/字/雙字（有號/無號共 6 種） |
| SB/SH/SW/SD | S | 儲存位元組/半字/字/雙字 |
| BEQ/BNE/BLT/BGE/BLTU/BGEU | B | 條件分支（PC-relative） |
| LUI | U | 載入高位立即數，`x[rd] = {imm[31:12], 12'b0}` |
| AUIPC | U | PC 加高位立即數，`x[rd] = PC + {imm[31:12], 12'b0}` |
| JAL | J | 跳躍並連結，`x[rd] = PC+4; PC = PC + imm_j` |
| JALR | I | 間接跳躍並連結，`x[rd] = PC+4; PC = (x[rs1] + imm_i) & ~1` |

### 關鍵模組

| 模組 | 位置 (rv64i_cpu.v) | 說明 |
|------|--------------------|------|
| Program Counter | lines 25–30 | 64-bit PC，posedge 更新，reset 歸零 |
| Instruction Memory | lines 37–41 | 1024 × 32-bit，預填 NOP，`$readmemh` 載入測試程式 |
| Register File | lines 57–60 | 32 × 64-bit，x0 硬體歸零 |
| Data Memory | lines 62–64 | 8KB byte-addressable (`reg [7:0] dmem [0:8191]`) |
| Immediate Generator | lines 66–72 | I/S/B/U/J + Z 五種立即數產生 |
| Control Unit | lines 107–166 | 單一 `always @(*)`，預設值全零 |
| ALU Control | lines 225–267 | 根據 opcode + funct7 + funct3 選擇 ALU 操作 |
| ALU Datapath | lines 275–320 | 組合邏輯計算結果 |
| Branch Comparator | lines 322–330 | BEQ/BNE/BLT/GE/BLTU/BGEU |
| Data Memory Read | lines 344–362 | 依 funct3 載入不同寬度（有號/無號） |
| Register Write-back | lines 364–370 | 多工器選 ALU / 記憶體 / PC+4 / imm_u |
| Data Memory Write | lines 378–405 | 逐 byte 寫入（避免 LHS concatenation） |

## 設計決策

- **x0 歸零**：用 conditional assign `(rs1 != 0) ? rf[rs1] : 64'b0`（不消耗閘極）
- **資料記憶體 byte-addressable**：`reg [7:0] dmem [0:8191]`，避免 iverilog 的 LHS concatenation hang bug
- **控制單元預設歸零**：所有控制訊號在 `always @(*)` 入口歸零，case 內只設需要的位元
- **`$readmemh` warning**：「Not enough words」正常 — imem 已預填 NOP，hex 只需提供測試指令
- **S-type store 的 immediate**：`alu_b` 多工中根據 `opcode==7'b0100011` 分派 `imm_s`

## 測試

測試程式 (`program.hex`) 涵蓋以下情境：

- ADDI/ADD/SUB 基本運算（x1=42, x2=58, x3=100, x5=58, x6=0）
- LD/SD 記憶體存取（x4=100, mem[0]=100）
- BEQ/BNE 條件跳躍（x28=11，跳過 x9=1）
- LUI/AUIPC（x10=0x12345000, x11=0x40）

驗證條件：`x28==11 && x3==100 && x4==100 && x10==0x12345000 && x6==0`
