# 01 － 第一個 Rust 程式（hello.rs）

## 這課你將學會

- 知道一支 Rust 程式從哪裡開始執行
- 用 `println!` 輸出文字，並做出基本的格式化
- 分清楚「註解」、「字串字面值」與「巨集」

## 核心觀念

1. **程式入口是 `fn main()`**：編譯器會找 `main` 函式作為起點，`main` 通常不寫回傳值。
2. **`println!` 是巨集（macro）不是函式**：所以名字後面有驚嘆號 `!`。巨集會在「編譯期」展開成程式碼。
3. **`{}` 是格式化洞**：後面的參數依序填進去；也可以用 `{0}`、`{1}` 指定順序，或直接寫 `{變數名}`。
4. **兩種註解**：`//` 單行、`/* ... */` 多行（不能巢狀疊加）。

## 編譯與執行

在 `rust/` 資料夾下：

```bash
rustc --edition 2021 01/hello.rs -o hello
./hello
```

或一次編好並執行：

```bash
./run_all.sh 01
```

`--edition 2021` 表示使用 2021 版語言標準（本教材一律加上，第 18 課的多檔案模組一定需要）。

## 逐步解讀

### 1. 程式的骨架

```rust
fn main() {
    println!("Hello, world!");
}
```

`fn` 宣告函式，大括號裡是函式體。Rust 不需要在行尾加分號以外的東西，但**每個陳述式結尾都要有分號 `;`**。

### 2. 印出變數

```rust
let name = "Rust";
println!("我正在學 {name}");
```

`let` 建立變數（下一課 02 會仔細講）。`{name}` 會被換成變數的值，這比 `println!("{}", name)` 簡短。

### 3. 格式化選項

```rust
println!("印不出來的除法：{:.2}", 1.0 / 3.0);   // 0.33：冒號後是格式，.2 表示小數兩位
println!("寬度 10 右對齊：|{:>10}|", 42);        // > 右對齊，10 是寬度
println!("重複字元：{}", "-".repeat(40));         // "-" 重複 40 次
```

`.repeat(40)` 這種「在字串後面加小圓點呼叫東西」的寫法，是方法呼叫（method call），後面 09、13 課會常看到。

## 動手試試看

1. 把 `{0} 很棒，{1} 也很棒，再說一次 {0} 很棒` 改成只印一個參數，看看差別。
2. 把 `1.0 / 3.0` 改成 `{:.5}`、`{:.0}`，觀察小數位數。
3. 加一行印出你自己的名字與今天日期。

## 故意犯錯（請真的動手做）

1. 把 `println!("Hello, world!")` 最後的分號拿掉 → 編譯會通過（`main` 的最後一式是表達式也可以），但再往前一行拿掉分號就會看到錯誤。
2. 把 `println!(...)` 寫成 `println(...)`（去掉驚嘆號）→ 錯誤訊息會說找不到 `println` 這個函式，這告訴你：**驚嘆號是巨集的一部分**。
3. 只寫 `fn main() {}` 並且把 `println!` 全拿掉 → 能編譯，但什麼都不會印，確認 `main` 真的是入口。

讀錯誤訊息是學 Rust 最重要的技能，請務必把錯誤訊息從頭看完，不要只看第一行。
